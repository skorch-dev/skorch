This repository is in a low development stage. This means it will be maintained in the future and some features may be added on occasion, but overall, feature development has stopped. We also won't accept pure AI submissions; this is not because we're against them, but because we want to promote humans learning in the process.

We accept the following PRs in skorch:

- Fixing issues caused by updates in its (optional) dependencies, e.g. updates to PyTorch, scikit-learn, pandas, or Transformers.
- Keeping CI up-to-date, e.g. when new Python or PyTorch versions are released.
- Usage bugs: If you use skorch and run into a bug, open an issue and report the problem. Maintainers will decide if this bug should be fixed.
- Adding big features: If you have an idea to add a feature which would substantially extend skorch, create an issue and maintainers will decide if it's a good addition.
- Changes to the docs if the docs are substantially outdated or incorrect.

PRs that will not be accepted:

- Small bug fixes discovered by sending an AI agent to find bugs in skorch.
- Bug fixes authored purely by AI agents even if they address an open issue.
- Small features without clear use cases.
- Small adjustments to the docs or typo fixes.
